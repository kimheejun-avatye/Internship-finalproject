# 협업 규칙

실행 방법, 기능별 작업 분담, API 요청·응답 약속을 이 폴더에서 관리한다. 구체적인 규칙은 팀 합의 후 작성한다.

## 소속과 서비스 이용 범위

AVATYE와 GURU는 하나의 서비스 안에서 함께 협업하는 두 소속이다. `team`은 회원가입 때 저장한 사용자 정보로, 표시와 검색에 사용한다. 소속에 따라 사용자 목록이나 서비스 이용 권한을 제한하지 않는다. ‘AVATYE 메신저’는 서비스 이름이다.

- 승인된 비차단 사용자는 소속과 관계없이 서로 조회하고 회의에 초대하며 개인·단체 채팅을 할 수 있다.
- 회의 참석자는 `user_id`로 저장하며, 주최자도 참석 인원과 회의실 정원에 포함한다.
- 로그인·승인·차단 검사, 관리자 역할, 채팅방의 실제 참여자 검사는 유지한다. 모든 사용자와 대화할 수 있다는 의미가 다른 사람의 채팅방을 열람할 수 있다는 의미는 아니다.
- 별도의 ‘내 소속’ 선택기는 두지 않고, 로그인한 사용자의 기존 소속 정보를 표시한다.
